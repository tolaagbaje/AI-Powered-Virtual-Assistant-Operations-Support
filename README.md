## 🗂️ AI Prompt Library for VA Tasks

A collection of reusable prompts I use daily to get consistent, high-quality outputs from AI tools.

### 📧 Professional Email Draft
```
You are a professional communication assistant.
Draft a [tone: professional/friendly/formal] email from [sender role]
to [recipient role] regarding [topic].
Key points to include: [bullet points]
Length: [short/medium/detailed]
Call to action: [what should the recipient do?]
```

### 📋 Meeting Summary & Action Items
```
You are an executive assistant. Given the following meeting notes [INPUT],
produce a structured meeting summary including:
- Meeting date and attendees
- Key discussion points (bullet format)
- Decisions made
- Action items with owner and deadline
- Next steps
Keep it concise and professional.
```

### 🔍 Research Summary
```
Research the following topic: [TOPIC]
Produce a structured summary including:
- Overview (2-3 sentences)
- Key findings (5-7 bullet points)
- Relevant data or statistics
- Implications or recommendations
- Sources to explore further
Format in clear, readable markdown.
```

### 📄 SOP Draft
```
You are a process documentation specialist.
Create a step-by-step SOP for the following task: [TASK DESCRIPTION]
Include: purpose, scope, tools required, step-by-step instructions,
common issues and solutions, and a completion checklist.
Write for someone performing this task for the first time.
```
